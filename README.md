# Barro Mate

Tienda online de mates y cerámica artesanal. Pre-entrega del curso de React.

**Stack:** React 18, Vite, react-router-dom v6, Context API.

## Correr el proyecto
```
npm install
npm run dev
```

## Estructura
- `src/components`: Layout, Header, NavBar, Footer, CartWidget, Item, ItemListContainer
- `src/context/CartContext.jsx`: estado global del carrito
- `src/pages`: Home, Productos, ProductoDetalle, Carrito
- `public/productos.json`: catálogo local
